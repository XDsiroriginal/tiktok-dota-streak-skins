Набор кастомных скинов огоньков (Streak Flames) для личных сообщений TikTok по мотивам персонажей **Dota 2**. Включает в себя высокополигональные чиби-маскоты, 4 стадии роста пламени для каждого героя, интерактивный веб-симулятор чата TikTok и автоматический установщик/экспортёр ассетов для Android.

---

## 🎮 Интерактивный симулятор чата

В проект встроен интерактивный симулятор интерфейса TikTok:
- **Запуск:** откройте файл `viewer/index.html` в любом браузере.
- **Возможности:**
  - Переключение между всеми 12 героями Dota 2 в один клик.
  - Ползунок дней стрика от 1 до 250 дней с живым отображением смены стадий.
  - Превью в реальном чате сообщений TikTok с анимацией пульсации на стадии 100+ дней.

## 📈 Стадии роста огонька

Для каждого героя автоматически генерируются 4 стадии эволюции:
1. **Стадия 1 (1–7 дней):** *«Искра»* — маленький зарождающийся огонёк с мягким свечением.
2. **Стадия 2 (8–29 дней):** *«Рост»* — сформировавшееся пламя персонажа.
3. **Стадия 3 (30–99 дней):** *«Зрелое пламя»* — 100% детализированный огонёк со всеми элементами героя.
4. **Стадия 4 (100+ дней):** *«Эпическое сияние»* — легендарный огонёк с золотым нимбом, искрами и светящимся ореолом.

## 🛠️ Установка и экспорт

### Быстрый старт на ПК:
1. Запустите `install.bat` в корне проекта.
2. Откроется удобное меню менеджера:
   - Проверка подключения телефона по ADB (например, Samsung Galaxy Z Flip6).
   - Проверка наличия и версии установленного TikTok.
   - Экспорт набора ассетов нужного героя в плотности Android (`drawable-mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`) в архив `.zip`.
   - Запуск веб-симулятора.

Подробная инструкция по установке через **LSPatch** и базы **ReVanced** находится в [docs/INSTRUCTIONS_RU.md](docs/INSTRUCTIONS_RU.md).  
Технический реверс-инжиниринг отчёт по защите ByteDance MetaSec находится в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## 📂 Структура репозитория

```
├── skins/              # Мастер-арты 1024x1024 (CM, Lina, QoP, Luna, Mirana, etc.)
├── stages/             # Нарезка по 4 стадиям для каждого персонажа
├── viewer/             # Интерактивный веб-симулятор интерфейса TikTok (HTML/JS)
├── installer/          # Консольный установщик (Python + .bat)
├── docs/               # Полные инструкции и архитектура
├── build_stages.py     # Скрипт автоматической нарезки стадий
└── install.bat         # Лаунчер установщика
```
