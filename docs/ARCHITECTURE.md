# Архитектура и анализ безопасности TikTok (Reverse Engineering Report)

## 1. Спецификация целевого устройства и окружения
- **Устройство:** Samsung Galaxy Z Flip6 (`SM-F741N`)
- **ОС:** Android 14 / One UI 6.1 (API Level 34/36)
- **Целевое приложение:** `com.zhiliaoapp.musically` (TikTok International)
- **Версия:** `47.0.3` (билд `2024700030`)
- **Размер APK:** 472,380,973 байт (~472 МБ)

## 2. Анализ защитных механизмов ByteDance

### 2.1. Упаковщик и заглушка (DEX Stub Loader)
Корневой файл `classes.dex` в дистрибутиве занимает всего **11,704 байта**. 
Он выполняет роль протектора:
- Перехватывает вызов `Application.attachBaseContext()`.
- Инициализирует нативные библиотеки безопасности (`libropaencrypt.so`, `lib_jhmp.so`).
- На лету расшифровывает основной пул скомпилированного байткода из защищённых нативных контейнеров (`libdex_df_im_bootfinish.so`, `libdex_df_search_biz.so` и др.).

### 2.2. Модуль MetaSec (`libmetasec_ov.so`)
MetaSec — это проприетарная система безопасности ByteDance, включающая:
1. **Проверку целостности подписи (Signature Check):** сверяет хеш сертификата приложения с официальным ключом Google Play. При несовпадении генерируется внутреннее исключение либо тихий аборт сетевых запросов.
2. **Детект модификации окружения:** сканирует пространство памяти на наличие отладчиков, ptrace, Frida, Magisk/Zygisk, Xposed-хуков.
3. **Play Integrity API:** запрашивает аппаратный токен у серверов Google Play Services, подтверждающий подлинность сборки.

### 2.3. Механизм отображения и кэширования стриков
Визуализация огоньков в переписке TikTok построена на базе:
- Графической библиотеки **Facebook Fresco** (кэш в `fresco_cache` и `fresco_custom_cache`).
- Движка динамической доставки ассетов **Gecko CDN** (`gecko_channels`), позволяющего ByteDance загружать сезонные анимации без обновления APK.

## 3. Рекомендуемые архитектурные решения

```
┌────────────────────────────────────────────────────────┐
│                      Пользователь                      │
└───────────────────────────┬────────────────────────────┘
                            │
               ┌────────────┴────────────┐
               ▼                         ▼
    ┌──────────────────────┐  ┌──────────────────────┐
    │    LSPatch Module    │  │  Pre-Patched ReVanced│
    │ (Хук в памяти через  │  │ (База с отключённым  │
    │ Fresco ImagePipeline)│  │     libmetasec)      │
    └──────────┬───────────┘  └──────────┬───────────┘
               │                         │
               └────────────┬────────────┘
                            ▼
    ┌────────────────────────────────────────────────────┐
    │              Dota 2 Streak Flame Pack              │
    │ (4 стадии роста: 1-7д, 8-29д, 30-99д, 100+д)       │
    └────────────────────────────────────────────────────┘
```

1. **LSPatch (Non-Root Hooking):**
   Инъекция собственного хука в `Fresco.getImagePipeline().fetchDecodedImage()` перехватывает URI запроса к официальному стикеру огня и возвращает растровый поток из локального кэша `build/<hero>_export/`.
2. **Resource Redirection:**
   Подмена локальных ресурсов внутри пропатченной базы ReVanced.
